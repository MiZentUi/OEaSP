# Операционные среды и системное программирование

Данный репозиторий содержит код выполненных лабораторных работ, а также отчеты к ним.

## Примерная структура лабораторной работы

```shell
LRN
├── include             # Заголовки
├── report              # Материалы отчета
├── scripts             # Скрипты запуска, тестирования и тд.
├── src                 # Исходный код 
└── TASK.md             # Описание задания
```
